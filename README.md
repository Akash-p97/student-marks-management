# Student Marks Management

A Python-based project to manage student marks and calculate basic student results.

## Features

- Display student names and marks
- Calculate average marks
- Find highest marks
- Find lowest marks
- Count passed students
- Count failed students

## Technologies Used

- Python

## Python Concepts Used

- Lists
- Dictionaries
- Functions
- For Loop
- If/Else
- List Comprehension
- Built-in Functions

## How to Run

Run the following command:

python student_marks.py
